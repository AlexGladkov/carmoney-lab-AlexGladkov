# Режимы Kilo Code

Разница между режимами — в том, что агенту разрешено делать с проектом:

- **Code** — полный доступ: агент сам читает файлы, правит код и запускает команды.
- **Architect** — только планирование: агент разбирается в коде и пишет план, но файлы не меняет.
- **Ask** — только вопросы и объяснения: ничего не правит, отвечает по кодовой базе.
- **Debug** — как Code, но заточен под пошаговый разбор багов.

Итог: режимы отличаются «уровнем доверия» — от Ask (только читать и объяснять) до Code (делать всё).
